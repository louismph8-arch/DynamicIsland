## Opaline 1.33.2 — Claude Code always found

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 🤖 AI assistant: better Claude Code detection
For some people, Opaline said "Claude Code isn't installed" when it was. This is fixed in two ways:

- **A much wider search.** Opaline now looks at:
  - Windows' **up-to-date** PATH (before, installing Claude Code after Opaline started went unnoticed until the PC restarted);
  - the **npm** install (`%AppData%\npm`), even without the `claude.cmd` shortcut;
  - **nvm** and **Volta** installs (Node version managers);
  - the **native** install (`~\.local\bin`) and Claude Code's "local" install (`~\.claude\local`).
- **You can point to it yourself.** In **Settings → Island → AI assistant**, the Claude Code card has a **"Choose the file…"** button: pick `claude.exe`, `claude.cmd` (often in `%AppData%\npm`) or `cli.js`. Opaline then uses it first. **"Automatic search"** brings back normal detection.
- The card now shows **where Claude Code was found** (or the file you chose), and what to do if it can't be found.
- In the island, when Claude Code can't be found, the error offers a **"Choose Claude Code…"** button that takes you straight to the right place.
