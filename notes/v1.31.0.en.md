## Opaline 1.31.0 — Stage Manager and friends' widgets

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 🪟 Stage Manager
- Like on macOS: the active window in the middle, the others as thumbnails on the left, one click to swap (animated). One per screen.
- Turn it on in Settings → Dock, the Controls tab or the palette ("stage manager"). When you turn it off, your windows go back where they were.

### 🧩 Friends' widgets
- Create or install widgets **without code** (`.opalinewidget` files): time, weather, music, CPU, friends… on the desktop and in the island.
- A widget can read a website only if you allow it. A broken widget shows "unavailable", never a crash.
- Settings → Widgets → "Create a widget": a template, 2 examples and the docs.
