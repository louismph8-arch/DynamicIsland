## Opaline 1.33.2 — Claude Code toujours trouvé

Télécharge **Opaline-Setup.exe** ci-dessous. Si Opaline est déjà installée, elle se met à jour toute seule.

### 🤖 Assistant IA : Claude Code mieux détecté
Chez certains, Opaline disait « Claude Code n'est pas installé » alors qu'il l'était. C'est corrigé de deux façons :

- **Une recherche beaucoup plus large.** Opaline regarde maintenant :
  - le PATH de Windows **à jour** (avant, une installation de Claude Code faite après le lancement d'Opaline passait inaperçue jusqu'au redémarrage du PC) ;
  - l'installation **npm** (`%AppData%\npm`), même sans le raccourci `claude.cmd` ;
  - les installations par **nvm** et **Volta** (gestionnaires de versions de Node) ;
  - l'installation **native** (`~\.local\bin`) et l'installation « locale » de Claude Code (`~\.claude\local`).
- **Tu peux le désigner toi-même.** Dans **Paramètres → Île → Assistant IA**, la carte Claude Code a un bouton **« Choisir le fichier… »** : choisis `claude.exe`, `claude.cmd` (souvent dans `%AppData%\npm`) ou `cli.js`. Opaline s'en sert alors en priorité. Le bouton **« Recherche automatique »** remet la détection normale.
- La carte indique maintenant **où Claude Code a été trouvé** (ou le fichier que tu as choisi), et que faire s'il est introuvable.
- Dans l'île, quand Claude Code est introuvable, l'erreur propose un bouton **« Choisir Claude Code… »** qui t'emmène directement au bon endroit.
