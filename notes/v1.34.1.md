## Opaline 1.34.1 — Claude Code bien reconnu

Télécharge **Opaline-Setup.exe** ci-dessous. Si Opaline est déjà installée, elle se met à jour toute seule.

### 🤖 Assistant IA : plus de confusion avec l'application Claude
- Si tu as **l'application Claude** (celle du Microsoft Store, pour discuter avec Claude dans une fenêtre), elle s'appelle aussi `claude.exe`. Opaline la prenait parfois pour **Claude Code** (l'outil en ligne de commande) : la carte affichait alors « état de connexion illisible » ou « n'est pas installé » alors que Claude Code était bien là.
- Maintenant, la **recherche automatique ignore l'application Claude** (même quand Windows la met dans le PATH) et trouve le vrai Claude Code.
- Et si tu choisis l'application Claude avec **« Choisir le fichier… »**, Opaline te le dit clairement (« C'est l'application Claude, pas Claude Code ») et t'explique quel fichier choisir.

### 💡 Bon à savoir
- Pour poser des questions à **Opus 5.5** avec Claude Code, il faut une version récente de Claude Code. Si l'île te dit « Ton Claude Code est trop ancien », clique sur **« Mettre à jour »** (dans l'île ou dans Paramètres → Île → Assistant IA) : une fenêtre lance la mise à jour de Claude Code, puis repose ta question.

### 🛠️ Rappel de la 1.34.0
- L'île s'ouvre comme un liquide, les tuiles réagissent à la souris, les onglets glissent, et deux options d'accessibilité (« Réduire les animations », « Réduire la transparence »).
