## Opaline 1.27.0 — Sturdier

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 🛡️ Fewer crashes
- **Watchdog**: if Opaline stops suddenly, it restarts by itself (at most 3 times in 10 minutes, then in safe mode with a clear message).
- An island tab that crashes is **hidden for the session**: the island keeps going.
- Windows signals (waking from sleep, screens, windows) can no longer crash the app; an unplugged screen = the island comes back on the main screen.

### ⚙️ Settings
- A setting that can't be saved or applied now shows **a clear banner** (antivirus, full disk, safe mode, stopped module…) instead of doing nothing.
- “Start with Windows” also sees the choice made in Task Manager.

### 🧲 Dock
- A minimized app comes back **exactly as before** (maximized, size, position, screen).
- **Drag and drop** to reorder: icons move apart smoothly, the order is kept.
- The Windows Update icon refreshes right after installing, when waking from sleep and at every launch.

### 🏝️ Island
- The island no longer blocks clicks around it (browser tabs): only on its shape.
- **Connected devices** in the Controls tab: headset, controller, mouse, USB drives, with the battery when Windows provides it.

### 🖼️ Wallpaper
- **Keep Opaline's wallpaper**: if Windows, a theme or Spotlight changes it, it's put back right away (can be turned off in Settings → Wallpaper).

### Also
- Welcome guide reworked: every step works, “Back” everywhere, nothing is lost with Esc; replay it from Settings → About.
