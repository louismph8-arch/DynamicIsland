## Opaline 1.31.6 — Less memory

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 🧠 Memory
- Fixed: Opaline grew over the day. The graphics card counter (Widgets, Health) and icons kept at large size (palette, search, shelf, mixer) no longer pile up.

### 🛠️ Also since 1.31.1
- The **NVIDIA** overlay (Alt+Z) is no longer mistaken for a game: the island, dock and Stage Manager no longer hide for nothing.
- The island that follows the mouse no longer goes to a screen with a game or a full-screen video.
- Stage Manager: the column hides by itself, a handle on the left edge brings it out, the window in the middle fills the screen.
