## Opaline 1.25.0 — automations

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### ⚡ Automations
- New **Settings → Automations** page: “**When…** then…” rules, like Shortcuts on Mac.
- **When**: a game starts or ends, an app opens or closes, at a set time (on chosen days), a headset, controller or USB stick is plugged in, the PC is idle, the PC wakes up.
- **Then**: switch profile, change **audio output** (headset ↔ speakers), mute or unmute the mic, open an app, open a folder, start a timer, change wallpaper, **Do not disturb**, show a message.
- Ready-made example: “**When a game starts → Gaming profile + headset + Do not disturb**” (and the reverse when the game ends). A rule does nothing until you turn it on.

### 🔕 Do not disturb
- No more notices in the island meanwhile (devices, downloads, friends…). Timers you start still ring.
