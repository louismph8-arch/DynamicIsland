## Opaline 1.29.0 — What's new

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 📋 Clipboard
- New **Clipboard** tab: everything you copy (text, links, images), kept even after a restart, in an encrypted file. Pin, delete, filter.
- **Password vault**: add your passwords yourself, copy them in one click. They are never shown in the island.
- A password copied from a password manager never enters the history: the island offers to **keep it in the vault**.

### 🔊 Sound
- New **Mixer** tab: each app's volume, plus the main volume. A dock button opens it (scroll = volume).

### 🧲 Dock
- **Power** button: lock, sleep, restart, shut down (always asks first).
- Windows Update: **Update and restart / shut down**, only when you click.
- A small arrow tucks away the **background icons**; the desktop arrow tucks them away too.

### 👥 Friends
- **Friends** page in the settings: requests, block, mute a friend's notices.
- Right-click a friend in the island: status, a **quick message** ("Wanna play?"…), mute, remove, block.

### 🤖 AI assistant
- Your choice: Claude Code, Claude with an API key, **ChatGPT with an API key** or **ChatGPT with your subscription** (Codex). Real conversations.

### ✨ Also
- Discord: the island announces who **joins your voice channel**.
- Opaline-colored lighting for **Razer, Corsair and SteelSeries** too.
