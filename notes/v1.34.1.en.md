## Opaline 1.34.1 — Claude Code properly recognized

Download **Opaline-Setup.exe** below. If Opaline is already installed, it updates itself.

### 🤖 AI assistant: no more mix-up with the Claude app
- If you have **the Claude app** (the Microsoft Store one, to chat with Claude in a window), it's also called `claude.exe`. Opaline sometimes mistook it for **Claude Code** (the command-line tool): the card then showed "connection state unreadable" or "isn't installed" even though Claude Code was there.
- Now, **automatic search ignores the Claude app** (even when Windows puts it in the PATH) and finds the real Claude Code.
- And if you pick the Claude app with **"Choose the file…"**, Opaline tells you clearly ("This is the Claude desktop app, not Claude Code") and explains which file to choose.

### 💡 Good to know
- To ask **Opus 5.5** through Claude Code, you need a recent Claude Code. If the island says "Your Claude Code is too old", click **"Update"** (in the island or in Settings → Island → AI assistant): a window runs Claude Code's update, then ask again.

### 🛠️ From 1.34.0
- The island opens like a liquid, tiles react to the mouse, tabs slide, and two accessibility options ("Reduce motion", "Reduce transparency").
