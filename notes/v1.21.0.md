## Opaline 1.21.0 — la grosse mise à jour

Télécharge **Opaline-Setup.exe** ci-dessous. Si Opaline est déjà installée, elle se met à jour toute seule.
Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (l'app n'est pas signée) :
clique sur **Informations complémentaires → Exécuter quand même**.

### 📱 Télécommande sur ton téléphone
Paramètres → **Connecté** : active la télécommande, scanne le QR code avec ton téléphone, c'est relié.
- Musique, volume, **micro et casque** (ceux de Discord quand il est ouvert), profils, verrouiller le PC
- **Lancer tes applis**, ouvrir un lien sur le PC, **envoyer des photos et fichiers** du téléphone vers le PC, texte vers le presse-papiers
- **Pavé tactile, clavier, aperçu de l'écran**, fenêtres ouvertes, raccourcis
- Luminosité, thème sombre, fond d'écran, minuteur, message dans l'île, veille / redémarrer / éteindre
- Réseau local seulement, code d'appairage, « Contrôle complet » à activer téléphone par téléphone

### 🏝️ L'île
- **Annonces** quand tu connectes un casque, une manette ou une clé USB (avec la batterie si Windows la donne), et quand un téléchargement est terminé (glisse le fichier depuis l'île !)
- **Horloges du monde** (jusqu'à 4 villes)
- **Santé du PC** : processeur, mémoire, GPU et sa température (cartes NVIDIA), disques, applis les plus gourmandes ; alerte quand un disque est presque plein
- **Amis en ligne** : vois lesquels de tes amis sont en ligne et à quoi ils jouent (petit serveur gratuit à créer, guide dans Paramètres → Connecté)
- **Thèmes saisonniers** : Halloween, Noël, Nouvel An, Saint-Valentin (et quelques surprises cachées…)

### 🧭 Le dock
- Zone d'état : langue du clavier, mises à jour Windows, corbeille (glisse un fichier dessus), pile Téléchargements
- Bouton rapide pour revenir à la barre des tâches Windows (clic droit sur le dock, ou l'icône d'Opaline)

### ✨ Et aussi
- **Éclairage RGB** : tes appareils Logitech (G HUB) et ceux d'OpenRGB prennent la couleur d'Opaline
- **Mini Claude avec une clé API** Anthropic, pour ceux qui n'ont pas Claude Code (clé chiffrée par Windows)
- **Français / anglais**, mode sans échec (Maj au lancement), rapport de bug sans données personnelles, sauvegarde des réglages

Un souci ? Paramètres → À propos → **Exporter un rapport de bug**, et envoie-le.
